# Research Agent RAG

Агентная RAG-система (Retrieval-Augmented Generation) для глубокого анализа научных статей с механизмом динамического извлечения данных (On-the-fly Ingestion). 

Система автономно переводит запрос пользователя в оптимизированные поисковые теги, обращается к базе ArXiv, скачивает релевантные PDF-файлы, векторизует их в локальную базу данных и генерирует аналитический ответ со ссылками на источники.

## 🚀 Ключевые возможности

* **Автономный ресерч:** Интеграция с ArXiv API для поиска актуальных публикаций по заданному контексту (например, Causal Inference, Agentic RAG или ML-архитектурам).
* **On-the-fly Ingestion:** Скачивание, парсинг и векторизация PDF-документов "на лету" без необходимости заранее собирать статичную базу знаний.
* **Стейт-машина на LangGraph:** Модульная архитектура графа, жестко разделяющая логику поиска, скачивания, обработки и генерации для удобства тестирования и масштабирования.
* **Локальная векторизация:** Использование `fastembed` (модель `BAAI/bge-small-en-v1.5`) и локального инстанса `Qdrant` для быстрого создания векторного пространства без обращений к платным API эмбеддингов.
* **Академическая точность:** Жесткий системный промпт, минимизирующий галлюцинации LLM и обязывающий модель опираться строго на контекст скачанных статей.

## 🛠 Технологический стек

* **Оркестрация агента:** LangGraph, LangChain
* **LLM:** OpenAI API (GPT-4o-mini)
* **Векторная БД:** Qdrant (Local) + FastEmbed
* **Парсинг и извлечение данных:** PyMuPDF, ArXiv API
* **Управление окружением:** `uv`

## 🧠 Архитектура графа (Nodes)

1. **SearchNode:** Анализирует изначальный запрос пользователя через LLM, генерирует массив поисковых тегов и собирает метаданные релевантных статей через ArXiv API.
2. **DownloadNode:** Фильтрует дубликаты и асинхронно загружает PDF-файлы во временную директорию (с поддержкой кэширования ранее скачанных материалов).
3. **ProcessNode:** Извлекает сырой текст из PDF, разбивает его на смысловые фрагменты (RecursiveCharacterTextSplitter) и загружает векторы + метаданные в коллекцию Qdrant через нативный API.
4. **GenerateNode:** Выполняет семантический поиск по собранной коллекции и синтезирует итоговый мультидокументный ответ, сравнивая методологии авторов.
